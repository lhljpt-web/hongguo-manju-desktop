# 0.15beta 变更记录

日期：2026-11-12
基线：上游 0.1.4 运行时

## 修复
- 播放中间集/末集返回空响应（升级至 Argus/Ladon 551 + 7.4.3.32 签名，正文参与签名并使用 gzip）。
- 设备登记限流导致播放失败：登记身份 10 分钟复用，空响应时才强制刷新；模型请求 120ms 间隔。
- 仅提供 VVC（bytevc2）的分集：`device_level=1` 请求 HEVC 轨道；无 HEVC 时快速失败。
- 缺少 `encrypt_info` 的分集被误判为未知加密。
- 缓存「无法读写视频缓存」：检查点写入限流到 3 秒一次，改名遇 EPERM/EBUSY/EACCES 退避重试。
- 转码超时导致「视频处理未完成」：超时改为按时长计算，并增加一次 ultrafast 重试。

## 新增
- 单文件多线程分段下载（1–128 线程，断点按段续传）。
- 并行准备上限 128 与按剧集公平分配。
- 硬件编码自动探测（NVENC/QSV/AMF），失败回退 CPU；HEVC 直通硬解。
- 解码方式四档切换：自动 / 强制 GPU / 纯软件 / 仅直通硬解。
- CPU 解码档位三档（线程数与并发）。
- 网络状态检查（30 秒一次，显示在缓存页速度旁）。
- 播放报错 30 秒自动下一集（普通播放器与刷剧模式）。
- 刷剧模式（Demo）：独立窗口、竖向滑动、分类筛选（含言情）、个性化推荐。
- 缓存页底部「刷剧个性化推荐」管理卡片。

## 已知问题
- 刷剧模式未接入登录与付费内容。
- 硬件编码在部分驱动上可能花屏，可切换「纯软件」。
