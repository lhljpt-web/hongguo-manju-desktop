# 红果漫剧桌面版 0.1.9

恢复 Windows 完整分集取源。旧请求在多部当前作品上仅返回空结果或 360p 时，优先使用已核验的 Windows SDK 会话组件，并精确匹配目标分集；继续使用原有画质选择、完整时长及音视频解码校验。

切换分集、作品或画质会取消对应 SDK 子进程；退出及更新等待本应用拥有的 helper 进程树停止。保留旧后备路径、长集完整缓存和续播修复，不清空收藏、观看进度、身份配置或缓存。首次联网播放会准备本机匿名组件输入。

本轮验证作品为《病弱千金，百鬼让路第二季》与《为她失控 第三季》，分别按实际 165 / 320 集列表抽查首、中、末集。原生六个精确目标均通过本次联网 1080p 全片音视频解码，360p 预览不计入成功。详情见 [验证记录](../playback-fix-2026-11-25.md)。样本结果不代表所有作品始终可用；此前约 291 秒特定分集本轮未复测。

附件包含安装程序、自动更新元数据、本项目源码、SDK 组件对应源码及 SHA256 校验文件，不包含实际身份、签名、密钥或剧集媒体。

验证：216 项自动测试、类型检查与构建通过。两部当前作品六个精确目标在新建隔离目录中均通过发行包实际 1920×1080 音视频播放、全片解码、未缓存拖动及完整缓存拖动；同一 QA 缓存重启后在第 320 集 20 秒位置续播。搜索分页 10→20 与目标详情打开通过。续播控制明确属于已完成缓存播放，不计作新的联网取源成功。
