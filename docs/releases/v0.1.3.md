# 0.1.3 · 播放签名兼容与续播保护

**[下载 Windows x64 安装包](https://github.com/lhljpt-web/hongguo-manju-desktop/releases/download/v0.1.3/Hongguo-Manju-0.1.3-Windows-x64.exe)** · [安装指南](https://github.com/lhljpt-web/hongguo-manju-desktop/blob/main/docs/installation.md)

- 补全当前 GET 播放接口的专用签名，绑定实际分集、时间戳和本机匿名身份；空响应最多尝试三个来源域名，每次重新签名。
- 补充匿名登记所需的公开应用指纹，保留原有单次登记恢复边界，不反复轮换身份。
- 上次观看的分集不在当前来源列表中时，明确提示并保留记录，等待手动选集，避免自动播放其他集。

两部其他作品各抽查首集、中间集、末集：共六集重新下载，1080p 完整解码通过；192 项自动测试、类型检查、构建和桌面播放回归通过。缓存、收藏、观看进度保留，更新仍需点击下载、再次确认安装。

**已知限制：部分匿名身份仍会持续收到来源空响应；原 155 集作品目前只有 3 集出现在桌面接口和官网中，原第 78、155 集尚未恢复。本版不保证所有作品全集正常，亦未遍历所有分集。** 六集联网验证复用了本机本轮自行登记的有效身份，没有复用历史媒体缓存；全新身份的失败记录一并保留。详情见 [本轮调查与验证](https://github.com/lhljpt-web/hongguo-manju-desktop/blob/main/docs/playback-fix-2026-11-06.md)。

感谢 [hongguoTV](https://github.com/tsukiyo-zero/hongguoTV) 的公开修复记录，以及 [drpys](https://github.com/woshishiq1/drpys) 的 GPL-3.0 签名算法来源。第三方非官方客户端。
