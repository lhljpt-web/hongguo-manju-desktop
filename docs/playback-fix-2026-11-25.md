# 2026-11-25 Windows 完整分集取源修复

0.1.6 安装版及 0.1.8 发行版在本轮两部当前榜单作品上复现相同情况：详情、实际分集列表可访问，首集仅得 360p，中间集及末集无法取得模型。旧 GET/POST 请求返回 HTTP 200 空正文；登记字段格式有效不能证明该身份已获播放接口接受。当前 App preload 请求连同对应上游签名也在两部中间集上返回空正文。

固定版本的 Windows SDK 会话路径取得了所选分集的模型，并按原始返回中的分集键精确匹配。0.1.9 在主进程接入该组件，继续由原有 provider 选择可解码画质，原有媒体层验证完整时长、文件及音视频。SDK 失败时保留已有后备路径；取消当前任务会停止其 helper 进程树，退出及更新等待清理完成。

旧形态未返回模型、SDK 会话路径恢复取源是本轮可观测的区别；未确认服务器空响应的内部原因，不据此断言账号被封、作品下架或全站故障。此前约 291 秒特定分集问题未纳入本轮复测，不宣称已修复；保留原有长集编码预算回归。

源码记录组件精确摘要、原始来源和许可；发行同时提供 helper 对应源码及依赖源码包。用户收藏、观看进度、原身份与缓存不迁移、不清除；测试身份及媒体只存在于隔离 QA 目录，实际身份、签名、密钥和媒体地址不进入 GitHub。
