# 安装与使用

[返回首页](../README.md) · [最新正式版](https://github.com/lhljpt-web/hongguo-manju-desktop/releases/latest) · [问题反馈](https://github.com/lhljpt-web/hongguo-manju-desktop/issues)

## 下载与安装

当前正式版 **0.1.4**，支持 Windows 10 / 11 x64（64 位）。

**[下载 Windows 安装包](https://github.com/lhljpt-web/hongguo-manju-desktop/releases/download/v0.1.4/Hongguo-Manju-0.1.4-Windows-x64.exe)**

| 文件 | 用途 |
| --- | --- |
| Hongguo-Manju-0.1.4-Windows-x64.exe | Windows 安装程序，普通用户下载此文件 |
| SHA256SUMS-0.1.4.txt | 文件完整性校验 |
| Hongguo-Manju-0.1.4-source.zip | 对应版本的开发源码 |
| latest.yml | 软件更新元数据，无需手动打开 |

等待 .exe 下载完成后双击，按向导选择目录，安装后从桌面或开始菜单打开「红果漫剧桌面版」。安装包自带运行组件，无需另外安装 Node.js、Python、Java、手机 APP 或模拟器。暂不提供 macOS、Linux、Windows ARM64 版本。

安装包未配置 Windows 发布者代码签名。需要核对文件完整性时，在下载目录打开 PowerShell：

~~~powershell
Get-FileHash -LiteralPath '.\Hongguo-Manju-0.1.4-Windows-x64.exe' -Algorithm SHA256
~~~

将结果与同一发布页面的 SHA256SUMS-0.1.4.txt 对照；字母大小写不影响比较。

## 从旧测试版迁移

正式版本号从 **0.1.0** 开始，之前的测试版发行文件和标签已清理。旧测试版数字较高，自动更新不会将 0.1.0 识别为更高版本，需要手动覆盖安装一次。

1. 在系统托盘菜单选择「退出软件」，等待后台任务退出。
2. 下载当前正式版，覆盖到原安装目录。
3. 保留原应用数据目录，不必先卸载或清空缓存。

应用身份与数据目录不变，收藏、进度、设置、播放身份和完整缓存继续保留。以后正式版按版本号递增更新。遇到旧版卸载失败提示，可重启电脑后再覆盖安装，无需删除媒体缓存。

## 开始观看

通过推荐、热播、新剧榜单或搜索剧名打开作品。也可以点击「导入链接」，粘贴分享链接或包含链接的整段文字；导入后加入本机收藏。

播放器支持选集、上下集、倍速、音量、全屏与画中画。进度条可向前或向后拖动；尚未缓冲的位置会显示等待并保留最新目标，媒体可用后自动定位。可以在等待时重新选择位置，无需反复尝试同一目标。网络故障时无法保证立即跳转。

可在「外观」选择宣纸书卷、午夜影院、流光或像素放映厅。外观、播放偏好、收藏和观看记录保存在本机，不同步手机账号。

开启自动连播后，播完当前集进入下一集；仅在能确认唯一紧接后续季时跨季衔接。睡眠计划可按时间或集数停止播放。

## 缓存与退出

当前集优先准备。可选择「缓存当前整季」，或在缓存中心登记多部作品；支持暂停、继续、重试、限速、容量预算和缓存位置迁移。

缓存中心可设置两路、四路或六路任务，最多同时处理两集视频。处理时需要额外临时空间；达到预算或磁盘不足时会暂停新任务。断点续传取决于来源是否提供一致的资源校验信息。

关闭窗口后会驻留托盘并继续后台缓存。需要完全退出或安装更新时，使用托盘菜单中的「退出软件」。

## 常见问题

| 情况 | 处理方法 |
| --- | --- |
| 下载后找不到安装程序 | 下载 .exe，不要将 Source code ZIP 当作安装包 |
| 某一集无法播放 | 重试当前集；初次登记失败时退出软件后重开，仍失败可导出诊断反馈 |
| 拖动后等待 | 目标尚未缓冲时会自动准备并定位，可改选其他位置；检查网络和磁盘空间 |
| 画质低于预期 | 画质以来源实际轨道为准，可调整画质上限；软件不会补造高清 |
| 更新或安装提示文件被占用 | 从托盘完全退出软件后重试，仍失败可重启电脑 |
| 无法同步手机收藏 | 当前仅提供本机收藏、历史与缓存，不接入手机账号 |

反馈时请提供 Windows 版本、软件版本、作品与集数、复现步骤及错误提示。诊断文件不应包含账号、媒体地址或个人资料。

## 从源码运行（适合开发者）

需要 Windows x64、Node.js 22+ 和已准备的运行组件。源码归档不含完整运行组件，准备方式见 [运行组件说明](runtime-components.md)。

~~~powershell
npm ci
npm test
npm run typecheck
npm run build
~~~

将完整运行组件放入项目根目录的 runtime-bundle 后，再执行 npm start 或 npm run package:win。更新渠道与发布要求见 [应用内更新](auto-update.md)。
