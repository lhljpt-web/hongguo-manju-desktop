# 2026-11-08 播放身份恢复修复 · 0.1.4

## 原因与修复

0.1.3 长期复用已登记身份。独立对照确认，部分身份取得模型后，对其他分集的 GET 和 POST 都持续为空。使用同一份旧身份调整 Cookie、签名进程字段或换路没有恢复。为每个失败播放请求重新匿名登记后，同样三个失败分集均立即返回完整模型。

参考 [hongguo-drama 当前播放实现](https://github.com/jackotom/hongguo-drama/blob/b2b81cec61159ae788c723b21ad1015ac40296f6/src/native/app-source.js) 中按播放请求登记的做法，0.1.4 在既有 GET 路径耗尽后，为当前请求单独登记，向 POST `/novel/player/multi_video_model/v1/` 发送完整正文并重签。恢复身份仅用于当前请求，后台并发请求各自登记。本机持久化资料继续由原流程管理。

POST 签名绑定实际正文、分集和当前登记身份。正文模型按所选分集 ID 精确读取。登记或业务错误明确报错，一次恢复只发送一个 POST。后续用户重试可以重新登记。源码中没有把官方 App 的设备身份或账号用于恢复。

登记格式依据 hongguoTV 的 `DeviceRegister.kt`，更新到本轮实测成功的 7.3.9.32 头部字段与登记入口。签名算法继续采用原有 SM3 兼容实现，本轮只补充正文参与签名。
