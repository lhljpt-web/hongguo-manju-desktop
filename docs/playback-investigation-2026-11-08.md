## 公开库对照

查阅了 hongguoTV 截至 2026-11-07 的公开改动和 jackotom/hongguo-drama 当前源码。

- [hongguoTV 9e558433](https://github.com/tsukiyo-zero/hongguoTV/commit/9e55843380b7fb15d6e11f2780de0dc8ea637dd5) 增加进程 nonce、启动时间和签名 POST 形态。
- [hongguoTV 1b53a1e](https://github.com/tsukiyo-zero/hongguoTV/commit/1b53a1e7b7bd2982431410fcfa661ef5849e774d) 复用注册会话的签名上下文。
- [hongguo-drama app-source.js](https://github.com/jackotom/hongguo-drama/blob/b2b81cec61159ae788c723b21ad1015ac40296f6/src/native/app-source.js) 提供另一套完整签名 POST 形态。

本轮仅执行经检查的签名算法与本项目的网络请求，没有运行第三方安装包。全部设备身份由本机自行匿名登记，没有使用公开库的设备标识。

| 对照 | 结果 |
| --- | --- |
| 自行登记身份，注册响应携带 store-region、install_id、ttreq Cookie | 登记成功 |
| 进程随机 nonce、当前启动时间、浮点环境字段归零，加 Cookie 的签名 GET | 第227集返回模型，第454、238、475集为空 |
| 同一身份、同一时间窗口，带正文摘要和 Cookie 的签名 POST | 同样未恢复三个失败分集 |
| 签名环境字段按 Kotlin 明文 JSON 调整后复测 | 三个失败分集仍为空 |
| hongguo-drama 原始签名算法及其 POST 请求形态，注入本机身份 | 三个失败分集均为空 |

后两项均返回 HTTP 200 与 0 字节正文，尚未取得可用于媒体解码的资源。上述对照修改保留在忽略目录 outputs/repair-2026-11-08，没有合入生产代码。结果仅说明这些公开方案在本机样本中没有通过，无法据此认定官方 App 故障或作品下架。

## 剩余定位条件

需要官方 App 对相同作品、相同集数的当日播放结果与新分享链接，核对手机侧作品与分集映射。如果官方 App 可播而编号一致，则需要成功播放时的请求形态对照，进一步核实设备会话、接口、Cookie 和签名上下文。当前没有成功请求作为对照，无法将空响应进一步归因于某一个具体字段。

本轮还发现 GitHub CLI 当前未登录，后续上传需要恢复 lhljpt-web 的授权。公开源码查询通过无需登录的 GitHub 接口完成。
