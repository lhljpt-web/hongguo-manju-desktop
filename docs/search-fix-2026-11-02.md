# 2026-11-02 搜索故障与修复

## 原因

用户报告搜索不可用。使用当前生产 ContentProvider 真实请求，推荐榜返回 15 项、指定作品详情返回 155 集，但搜索返回 HTTP 403，响应码为 `search_rejected`。

静态阅读官网当前搜索页面和其发布的 `search.75bdf6ea70.js`、`async/k.9fdbd35e5d.js`、`async/0f.825bf7815b.js`，确认页面先初始化搜索上下文和浏览器环境，再获取 `/api/search/result`。仅请求上下文并携带其 cookie，仍然返回 403；使用实际 Electron 浏览器正常打开官网相同关键词页面则取得 HTTP 200 和搜索结果。这些对照说明直接接口请求与正常页面流程已有差异，但不能据此断言上游的全部校验条件。

官方页面为 `https://hongguoduanju.com/search/末世`；代码仅运行官网自身正常网页流程，没有复制或逆向生成验证参数，没有自动解验证码或读取外部浏览器个人数据。

## 实现

主进程 SearchBrowser 串行打开独立的后台官网窗口，通过 Electron 内置调试协议只观察本次关键词及页号匹配的搜索响应。响应文本交给既有大整数安全解析、分页校验和作品过滤逻辑。浏览器不接入本地 preload、Node 或应用 IPC；取得结果、失败、超时后关闭。退出软件时取消搜索并销毁窗口，更新仍按原先的用户确认流程执行。

不将榜单、演员或其他关键词结果当作本次搜索；拒绝或超时明确报错，不循环重试验证。官网搜索页面脚本的资源加载及额外进程开销是此次兼容方案的代价，任务结束即释放窗口。

## 验证

- 新的 provider 回归先在旧实现失败（仍发出被拒绝的原始请求），修复后通过。原有搜索分页、脚本不执行、大整数编号和无效输入测试保留。
- `npm test`：25 项 JavaScript 与 161 项 TypeScript/播放状态测试，共 186 项通过。类型检查和生产构建通过。
- `node scripts/search-browser-qa.mjs`：真实官网搜索“末世”，前两页各 10 个作品且编号序列不同；指定关键词命中 `7695370827507698713`；请求中关闭能取消并结束隐藏窗口。
- 实际打包客户端运行 `QA_SEARCH_ONLY=1 node scripts/search-qa.mjs`：UI 搜索返回 10 项，“发现更多”增加到 20 项且保留第一页；点击首项后详情标题与搜索卡片一致，隔离 profile 中正常退出。该模式不把打开详情当作视频播放成功。

本轮还对旧样本播放资源作了独立检查，部分请求遇到原生空响应及官网兼容资源不可用。该来源问题与搜索 HTTP 403 分开记录，不将搜索修复描述为全集播放恢复。本轮不修改播放协议、缓存策略或用户正式安装。

原始页面、测试 profile、截图和报告仅保留在忽略目录 `outputs/`。未上传 cookies、匿名身份、签名或媒体地址。尚未在另一台全新 Windows 上重做安装和搜索验收。
